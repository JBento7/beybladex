# Artes dos finishes (placar da arena)

Coloque aqui as 4 imagens dos tipos de finish, com **estes nomes exatos**
(tudo minúsculo, extensão `.png`):

| Arquivo      | Finish              | Pontos |
|--------------|---------------------|--------|
| `spin.png`   | SPIN FINISH         | +1     |
| `over.png`   | OVER FINISH         | +2     |
| `burst.png`  | BURST FINISH        | +2     |
| `xtreme.png` | XTREME FINISH       | +3     |

- Formato recomendado: **PNG com fundo transparente**.
- Se um arquivo não existir, o placar mostra um badge de texto colorido no lugar.

Para subir pelo GitHub: **Add file → Upload files**, arraste as imagens com
os nomes acima para dentro desta pasta (`public/finishes/`) e faça o commit.
